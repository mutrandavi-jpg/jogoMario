# Jogo Mario

## Descrição

O **Jogo Mario** é um jogo de plataforma 2D inspirado nos clássicos da franquia, desenvolvido para rodar no navegador. O jogador controla o personagem Mario, que deve percorrer as fases, desviar de obstáculos e inimigos, coletar itens e alcançar o final de cada nível.

## Objetivo

Este projeto tem dois objetivos:

- Desenvolver o Front-End do Jogo Mario, definido na atividade anterior;
- Praticar o uso de **Git** e **GitHub** para controle de versão e trabalho em equipe, utilizando repositório público, licença MIT, branches (`main` e `dev`), commits organizados e merge.

## Instalação

Pré-requisito: [Node.js](https://nodejs.org/) instalado.

```bash
git clone https://github.com/SEU_USUARIO/jogoMario.git
cd jogoMario/frontend
npm install
```

## Execução

A partir do diretório `frontend/`:

```bash
npm run dev
```

Em seguida, acesse no navegador o endereço exibido no terminal (geralmente `http://localhost:5173` ou `http://localhost:3000`).

> Os comandos podem variar de acordo com a tecnologia utilizada.

## Branches

- `main` — versão principal e integrada do projeto;
- `dev` — branch de desenvolvimento. O código é enviado primeiro para a `dev` e depois integrado à `main` por merge (ou Pull Request).
